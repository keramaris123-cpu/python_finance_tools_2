# python_finance_tools_2
B2B Shift & Employees Hours Tracker
- Είναι ένα εργαλείο σε Python για την αυτοματοποιημένη καταγραφή βαρδιών, τον υπολογισμό μισθοδοσίας και τη διαχείριση προσωπικού σε επιχειρήσεις εστίασης και B2B.

  Χαρακτηριστικά (Features):

- Καταχώρηση Βαρδιών & Σταθμισμένο Ωρομίσθιο: Υπολογίζει αυτόματα τις συνολικές ώρες εργασίας και τον σταθμισμένο μέσο όρο ωρομίσθιου (Weighted Average Hourly Rate) όταν ένας εργαζόμενος έχει διαφορετικές αμοιβές ανά βάρδια.
- **Αφαίρεση / Αναίρεση Ωρών:** Δυνατότητα διόρθωσης λανθασμένων καταχωρήσεων ωρών με έλεγχο ορίων (validation).
- **Πλήρης Διαγραφή Εγγραφών:** Αφαίρεση εργαζομένου από το σύστημα με χρήση της εντολής (del).
- **Αναφορά Μισθοδοσίας:** Υπολογισμός αναλυτικών αποδοχών ανά εργαζόμενο και συνολικού κόστους μισθοδοσίας (Total Payroll Cost).
- **Προστασία Εισόδου (Error Handling):Έλεγχοι με (try/except) για την αποφυγή σφαλμάτων κατά την πληκτρολόγηση δεδομένων.

  Τεχνολογίες & Δομές Δεδομένων
- Python 3
- Nested Dictionaries (Εμφωλευμένα Λεξικά): Για την αποτελεσματική οργάνωση δεδομένων ({ "Όνομα": {"hours": x, "hourly_rate": y} }).
- Interactive Menu (while True): Φιλικό περιβάλλον γραμμής εντολών (CLI).
